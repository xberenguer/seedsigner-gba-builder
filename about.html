THE DETAILS BEHIND THE DOWNLOAD

Open by design.
Local by default.

An independent community fork of SeedSigner 0.8.7 for Pi Zero 1.3 with the Plus 320 × 240 display. Bring your own GBA game. Make your own image.

Built on your device.

Your selected GBA or ZIP stays in browser memory. The tool downloads a public template with no game ROM, verifies its checksums, adds your game and creates a personal IMG. Your ROM is never uploaded. There are no accounts or analytics.

No commercial game ROMs are distributed with this project.

Small device.
Familiar controls.

V-Rally 3 is detected automatically and uses the racing preset. Standard GBA provides D-pad, A, B, Start and Select, without shoulder buttons. Game compatibility and speed vary. Audio and persistent game saves are disabled.

Hold the top + bottom side buttons for 2 seconds, then release all buttons to open SeedSigner. Reboot to return to the game.

Experimental.
Know the scope.

61 Python tests and 11 browser-engine checks passed, including V-Rally ZIP input and independent image readback. Desktop browser output matches the integration test.

Physical cold boot, display, buttons, gameplay, camera and signing qualification remain pending for this exact template. This fork has not received an independent security audit. Use disposable test seeds for validation.

The game and SeedSigner share one operating system. The entry combination is an interface gate, not authentication or a security isolation boundary. Never enter a seed into this website.
