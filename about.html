WHAT’S BEHIND THE BUILD

Open by design.
Local by default.

An independent community fork of SeedSigner 0.8.7. Your GBA game and SeedSigner share one SD card image, configured in your browser for a supported Pi Zero 1.3 display profile.

Your file stays yours.

The builder reads your .gba file, or extracts one GBA game from your ZIP, in browser memory. It downloads a public template with no game ROM, verifies its checksums, adds your game and creates a personal IMG and checksum file. Your ROM is never uploaded.

There are no accounts, analytics or third-party scripts. Fonts and images are hosted with the site. GitHub Pages receives normal requests for the site’s files and may log connection information. Local ROM processing does not make a website visit anonymous.

The builder never writes your SD card. You download the IMG and write it using a separate tool such as Raspberry Pi Imager. The image is lost from browser memory when you close the page, so download it before leaving.

Match the hardware.

The board target is Raspberry Pi Zero 1.3. Selecting a display profile changes the game layout and SeedSigner display settings; it does not make unrelated boards or displays compatible.

Games, within limits.

This version accepts GBA games up to 32 MiB, or a ZIP up to 40 MiB containing exactly one .gba file. Standard controls are D-pad, A, B, Start and Select. Advanced settings can map L/R shoulder inputs to existing HAT buttons, disable an input or use the racing preset’s combined actions. Game audio and persistent game saves are not provided. Emulator compatibility and speed vary.

Basic use needs only your display and game. V-Rally 3 is detected automatically and uses a dedicated racing preset. Advanced lets you change each of the eight HAT buttons and the SeedSigner shortcut. The other games shown are examples to source separately; no commercial or homebrew ROM is included in the public template. A file passing validation is not proof of playability.

Classic NES Mario compatibility: Super Mario Bros. (FSME) automatically uses a separate patched emulator. The original game file reaches the title and World 1-1 with movement and jumps in ARMv6 software tests. The original emulator remains in use for other games. Physical Pi Zero performance still needs confirmation.

Examples and evidence

  • Crash Bandicoot: The Huge Adventure — creator tested. The creator personally reported it working well on October 12, 2026. Hardware, display profile and build version were not specified.
  • Pokémon Ruby / Sapphire — not yet tested. The official Nintendo screenshot is an example, not a compatibility result. Persistent saves are not available; progress is lost when the session ends.
  • Classic NES Series: Super Mario Bros. — software checked. World 1-1 movement, jumps, question blocks and a Goomba stomp were captured with the ARMv6 runtime under software emulation. Physical gameplay and speed remain unverified.
  • Google Dino GBA port: an endless runner with jump and duck controls.
  • Celeste Classic 2 GBA port: D-pad to move, A to jump, B to grapple and Select to pause.
  • V-Rally 3: use your own game file with the dedicated racing preset.
  • 2048 Advance: uses D-pad, Start and Select.

The Crash result is a creator-reported gameplay check; it does not establish full hardware qualification. An earlier Dino hardware build was played, and V-Rally 3 ARM emulation and control behavior were checked. Celeste Classic 2, Pokémon and 2048 gameplay on this fork remain untested. Other examples do not have physical validation with this browser builder; compatibility and speed vary.

The images are captured game frames, not promises of performance on your device. See the game-frame source record. Games and their artwork retain their respective creators’ rights.

Experimental.
Know the scope.

Baseline software checks, image readback and browser integration results are recorded in the validation record. The v0.2.4 Advanced validation record adds strict configuration, custom mapping and shortcut recovery tests, ARMv6 software checks, and browser-engine assembly/readback. These checks establish software behavior; they do not replace a physical device test or confirm game playability.

Full physical qualification of the generated images, including cold-boot, display, buttons, sustained gameplay, camera and signing, remains pending. The creator-reported Crash gameplay result is a narrower check. This fork has not received an independent security audit. Use disposable test seeds while qualifying the build.

The game and SeedSigner share one operating system. By default, hold KEY1 + KEY3 for two seconds, then release every button for 80 ms to open SeedSigner. Advanced can select two or three physical HAT buttons, a hold time from 0.5 to 10 seconds, and a release time from 50 to 1,000 ms. The shortcut uses physical buttons independently of game mapping; use the shortcut shown with your download. This entry gesture is an interface gate, not authentication or a security isolation boundary.

Never enter a seed into this website. This is an independent community project, not an official or endorsed SeedSigner, BitKit or Strike release.
